# Session 25 labs: Final Project Workshop and Real Mobile Projects

Copy the whole `labs/` folder into your course folder once (`shoreline/labs/`), if it is not there yet. `TASKS.md` in
each lab says what to do and when you are done.

| Folder | What it is | Needs |
|---|---|---|
| `l10_1-final-project/` | Types first on a brief that is NOT one of the seven: Saltwick Kayak Hire. Domain types and `Record` tables, a value computed instead of stored, and the mock API's rules with their tests, practised inside a practice copy of the final-project kit's starter | `final-project-kit.zip` from Lesson 10.1, and a practice copy of its `starter/` with `npm ci` done |
| `l10_2-working-on-real-mobile-projects/` | A three-point estimate with the work phones add, `npm outdated` rows sorted into pinned, update and later, and (stretch) which release train a change leaves on | the shared lab install (`npm install` once in `shoreline/labs`) |

Neither lab changes `shoreline-crew` or your own final project. Lab 10.1 runs in a practice copy of the starter that
you delete afterwards; your final project starts from its own, clean copy (Lesson 10.1, Step 3). No phone is needed:
the starter's mock API answers in Jest exactly as it answers in demo mode on a phone.
