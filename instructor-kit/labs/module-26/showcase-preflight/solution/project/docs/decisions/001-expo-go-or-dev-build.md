# Decision: Expo Go or a development build for Milestone 4

Date: (Milestone 4)  Status: decided  Revisit when: the shop asks for a feature Expo Go does not include

## Context
The app uses no device feature outside Expo Go (haptics on "returned", a share sheet for the day's list).
Both staff carry Android phones.

## Options
1. Keep Expo Go for development; launch with an Android preview build.
2. Make a development build now (expo-dev-client).

## Decision
Option 1. Nothing in the brief needs a native module outside Expo Go.

## Consequences
The app name, icon and ids were only checked in the preview build (Milestone 6).
