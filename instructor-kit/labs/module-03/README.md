# Session 3 labs: View, Text and StyleSheet

The kit's `labs/` folder sits in your course folder (`shoreline/labs/`, next to `shoreline-api/` and
`shoreline-crew/`) and `npm install` has run once in `shoreline/labs` (Session 1). Work in the `starter/` folder;
`TASKS.md` says what to do and when you are done.

| Folder | What it is | Needs |
|---|---|---|
| `l2_1-view-text-and-stylesheet/` | CSS habits on a phone: what tsc reports, what is silently ignored, style arrays and a Text inside a Text, on three new components | the shared install; no API, no phone |

`npm test` runs Jest once (React Native's renderer, no browser, no phone), `npm run typecheck` is `tsc --noEmit`,
`npm run lint` is `npx expo lint`, `npm run web` shows the lab's components in the web preview (optional; stop it
with Ctrl+C). Nothing here changes `shoreline-crew`.
