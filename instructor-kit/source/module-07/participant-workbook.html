Lesson

2.5

Responsive, Platform-Specific and Themed UI

By the end you can
  • Read the window's size with useWindowDimensions, choose a layout with breakpoints in density-independent pixels, and explain why Dimensions.get at the top of a file goes stale
  • Handle real platform differences with Platform.OS, Platform.select, platform-only props and platform files (.ios.tsx, .android.tsx, .web.ts), and know when not to
  • Follow the phone's light or dark setting with useColorScheme, and design a dark set of color roles that passes the same contrast checks as the light one
  • Build a typed theme: palettes TypeScript keeps complete, a useTheme hook, and styles that are made once per theme
  • Give the navigator and the status bar the theme's colors, and fix the web preview's server-drawn first page
Key ideas
  • useWindowDimensions returns the window's width, height, fontScale and scale (dp) and re-renders when it changes; the window, not the device. Breakpoints by width (Shoreline Crew: 700); flex, percentages and maxWidth first. Dimensions.get at the top of a file goes stale.
  • Platform: Platform.OS, Platform.select (default), platform-only props (ios_…, android_…), platform files (.ios, .android, .web): tsc checks the plain file; keep variants tiny and same-typed. Size and features before platform.
  • Dark mode: app.json userInterfaceStyle: "automatic" (Android needs expo-system-ui, per Expo's docs), useColorScheme(), a dark value for every role: no pure black, lighter accents, the same contrast rules; some colors stay on purpose.
  • A typed theme: lightColors decides the roles; darkColors … satisfies ThemeColors; useTheme() for colors in props; createThemedStyles for style sheets (two sets made once). Never a hook at the top of a file.
  • Navigator and status bar: ThemeProvider with a navigation theme from the roles; StatusBar style light on dark. Web preview: server-drawn first page; useColorScheme.web.ts starts as 'light' (useSyncExternalStore's server snapshot).
  • Wide screens: useColumns() (700), rows of flex: 1 cells with an empty cell for a short row, content maxWidth: 960, alignSelf: 'center'.

Glossary

TermMeaning
useWindowDimensionsThe window's size (dp), fontScale and scale; re-renders when it changes
breakpointA width where the layout changes structure (Shoreline Crew: 700)
Platform.OS / Platform.select'ios', 'android' or 'web' / one value per platform, with default
platform filex.ios.tsx, x.android.tsx, x.web.ts: Metro picks one per platform
color schemeThe phone's light or dark setting (useColorScheme)
userInterfaceStyleapp.json: which schemes the app supports (automatic, light, dark)
satisfiesChecks a value against a type without changing its own type
createThemedStylesShoreline Crew's helper: style sheets made once per theme, picked by a hook
hydrationReact taking over a page a server drew first (the web preview)
ThemeProviderExpo Router's: gives the navigator (headers, tab bar, background) its colors
