Review · Navigation

Module 4 in four lines

  • Routes are files; [id] is a dynamic segment; params are strings
  • Tabs stay mounted; a modal is a stack route presented differently
  • Stack.Protected hides screens; the API protects data
  • A deep link only opens a screen; the anchor puts the tabs underneath
Review · Data

Module 5 in five lines

  • localhost is the phone itself: --host and the computer's address
  • Query on a phone: AppState and NetInfo feed its managers
  • SecureStore for tokens, AsyncStorage for settings, SQLite for records
  • Forms: Controller, the return-key chain, a schema with the API's words
  • Offline first: save, then send; one clientId per record

Review · Devices

Module 6 in five lines

  • Ask at the moment, explain first, a no is an answer, Settings when blocked
