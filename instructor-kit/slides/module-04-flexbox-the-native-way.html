Flexbox the Native Way

Every View is a flex column.

2.2 · Four defaults

What differs from CSS

  • flexDirection: column
  • flexShrink: 0
  • alignContent: flex-start
  • flex: one number
  • Children stack top to bottom
  • Nothing shrinks to fit
  • Wrapped lines stay at the start
  • flex: 1 = the rest
WHY Yoga lays it out on Android and iOS; the web preview uses the browser's flexbox.
2.2 · Mental model

The crew lining up on the beach

  • No directions: single file down the beach (column)
  • "Row": shoulder to shoulder along the tide line
  • justifyContent: where they stand along the line
  • alignItems: how they stand across it (stretch: dunes to water)
  • Nobody shrinks: the last ones stand in the sea
2.2 · Axes

justifyContent along, alignItems across

  • Column: main axis down, cross axis across
  • Row: main axis across, so justifyContent now works sideways
  • alignItems default stretch: children fill the cross axis
  • Switch to a row and the two swap jobs on the screen
WATCH The most common "it centered the wrong way".
2.2 · Sizing

Four ways to get a size

  • Exactly: width: 72
  • A share of the parent: '50%'
  • The rest: flex: 1 (ratios: 1 and 2 split 1 to 2)
  • Nothing: as big as the content
RULE Text in a row gets flex: 1 or flexShrink: 1.
