File-Based Routing

The folder is the map.

4.1 · Mental model

Signposts at the trailhead

index.tsx/ (the folder's own address)
cleanups/[id].tsx/cleanups/e08, /cleanups/e17, …
+not-found.tsxevery address nothing else matches

WHY Change the map by adding a file: nobody keeps a list that can go out of date.
4.1 · Mental model

The clipboard pile

  • router.push: a sheet on top; back shows the one underneath, as it was
  • router.replace: swap the top sheet, no way back to it
  • router.canGoBack(): false for a single sheet (opened from a link)
  • Link for go-there · router for code-decided
4.1 · Header options

Three places, the most specific wins

  • All screens: <Stack screenOptions={{ … }}>
  • One route: <Stack.Screen name="cleanups/[id]" …/> in the layout
  • From data: <Stack.Screen options={{ title: event.title }} /> in the screen
  • Colors come from ThemeProvider: dark mode for free
PLATFORMS iPhone: centered title, chevron with words · Android: arrow · web: an arrow link

4.1 · Typed routes

Where the types come from

  • Metro writes .expo/types/router.d.ts while it runs
  • A route added while Metro was stopped: stale types, tsc complains
  • Fix: start npx expo start, then run tsc again
  • Never edit the generated file

4.2 · Nesting

The root stack around the tabs

shoreline-crew/src/app/_layout.tsx
        {/* ...and these to one. The tabs are ONE screen of this stack, with their own headers */}
        <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
        {/* Until the cleanup has loaded and its screen sets its own title */}
        <Stack.Screen name="cleanups/[id]" options={{ title: 'Cleanup' }} />

        {/* A modal: it slides up over the tabs or a cleanup, instead of being pushed from the side */}

        />

4.2 · Common mistakes

Odd headers, and what they mean

  • A header titled "(tabs)": the root layout still names index
  • A back button "(tabs), back": set headerBackTitle
  • No tab bar and a header "index": index.tsx copied, not moved
  • An empty strip above the tab bar: the 'bottom' edge twice
