Teach React Native & Expo: Build and Ship a Mobile App

A ready-to-deliver course that takes React and TypeScript developers to iPhone and Android with Expo, building a store-ready phone app for a fictional beach-cleanup crew: native UI, navigation, offline data, device features, tests and release.

26 × 3 h = 78 h 3 parts, each runs alone 37 lessons 312 self-checks

Who It's For

Learners who know React and TypeScript and are new to mobile. Prerequisites: React 19 with TypeScript, TanStack Query, Zustand, React Hook Form with Zod and a test runner (the React + TypeScript course, or equivalent); no Swift, Kotlin or Mac. Programs: trainers, bootcamps, colleges, corporate L&D, workforce programs.

  • Part 2 Navigation, Data and Devices · 8 · 24 h

  • Every part ends in a project and assessment; Parts 2 and 3 open with a catch-up

What Learners Can Do After It

  • Build themed, accessible native screens and fast lists
  • Navigate with Expo Router: tabs, modals, sign-in, deep links
  • Reach an API from a phone, store data, work offline
  • Use the camera, location and notifications, asking well
  • Animate with Reanimated; test with Jest, RNTL and MSW
  • Build, update and prepare a release; ship a client project
