React Native & Expo: Build and Ship a Mobile App · Quick Setup

Get Ready in About an Hour

Before the first session: install Node.js 24 or newer and VS Code, make your course folder shoreline, start the Shoreline Crew API, create Shoreline Crew with create-expo-app, put Expo Go on your phone (or use the web preview), install the labs once and run the check. You need a laptop (Windows 10/11, macOS or Linux) with permission to install software. Do it at home. Stuck? The full Setup Guide covers every problem, the phone's network, the internet each session needs, the accounts (none paid) and joining at Part 2 or Part 3.

1 · Node.js (LTS, 24 or newer)

Windows / macOS: nodejs.org › LTS › the installer (.msi / .pkg), defaults. Linux: nvm, then nvm install --lts. In a new terminal:

node --version
npm --version

The Node version should start with v24 or higher (the API needs at least 22.18).

2 · VS Code and Git

  • Install VS Code (code.visualstudio.com) and the Expo Tools extension (the project recommends it; ESLint is optional). Install Git (git-scm.com) if git --version does not answer.

3 · The course folder and the API

  • Did the React + TypeScript course? Use your shoreline folder: the API is the same. Otherwise make a folder shoreline (not in OneDrive, iCloud or Dropbox) and unzip shoreline-api.zip into it (from the course site or your instructor). shoreline/shoreline-api/server.ts must exist.
  • Open shoreline in VS Code (File › Open Folder…), then in the terminal (View › Terminal) start the API and leave it running:
cd shoreline-api
node server.ts

4 · Shoreline Crew

In a second terminal, in shoreline (answer y if npx asks; about 560 packages; do not run npm audit fix --force, and leave the template as it is: Session 1 resets it):

npx create-expo-app@latest shoreline-crew

5 · Expo Go, or the web preview

  • Phone? Install Expo Go from the App Store or Google Play (same Wi-Fi as your laptop). No phone? Fine: the web preview (press w in npx expo start) works for every session and lab.

6 · Labs: one install, then the check

Copy the labs/ folder from your instructor into shoreline, then install it once (about 1.1 GB, the only lab install of the course). With the API running, in the second terminal:

cd labs
npm install
cd ..
node labs/module-01/l1_0-orientation/check_environment.mjs
✅ Done when the last line says READY (or READY WITH NOTES) for React Native & Expo: Build and Ship a Mobile App

Send that line to your instructor. Before Session 1, READY WITH NOTES with "shoreline-crew is still the template" is expected. NOT READY? Fix the FIX lines from the top and run it again; still stuck: the Setup Guide, the course's troubleshooting.html, or Session 1's install clinic.

If something goes wrong

You see…Try this
node "not recognized" / "command not found"Close every terminal (VS Code too) and open a new one.
ERR_UNKNOWN_FILE_EXTENSION from node server.tsYour Node is too old: install the current LTS, then a new terminal.
FIX nothing answers at …Start the API: cd shoreline-api, node server.ts, leave it open.
FIX no shoreline-crew hereRun the check from shoreline; create the app there (step 4).
Expo Go cannot connectSame Wi-Fi? iPhone: Local Network on. WSL: the Setup Guide. Else the web preview for now.
