📱 React Native & Expo: Build and Ship a Mobile App

You already build web apps with React and TypeScript. This course takes those skills to the phone in everyone's pocket: real iOS and Android apps, written in the React and TypeScript you know, drawn with the platform's own native controls. In ten modules you build one app from an empty folder to a store-ready build: Shoreline Crew, the app volunteers carry to the beach to find a cleanup, sign up, check in on the sand, log what they collect even without a signal, and photograph the haul. Then you plan and ship one of your own.

📚 About This Course

React Native lets one team build for iOS and Android at once, and Expo is the framework the React Native team itself recommends for starting new apps. Most of what you know carries straight over: components, props, state, hooks, TypeScript, TanStack Query, Zustand, React Hook Form and Zod. What changes is everything around them: there is no DOM and no CSS, the screen has notches and a keyboard that covers your form, the network comes and goes, and the app has to ask before it uses the camera or your location. That is what this course teaches.

Every lesson explains why before how, uses code that was run and checked on the current tools (type-checked, linted, tested and bundled for web, Android and iOS), and ends with a project step for Shoreline Crew, a short quiz and a learning journal prompt. If you fall behind, each lesson's starting and finished code is a download away.

What You'll Learn

  • How React Native works: native views instead of a DOM, the New Architecture in plain words, and what Expo, Expo Go, development builds and EAS each do
  • Screens without HTML or CSS: View, Text, StyleSheet, flexbox with mobile defaults, images and icons, fonts, safe areas, touch, the keyboard, dark mode and platform differences
  • Fast lists (FlatList, SectionList, FlashList) and file-based navigation with Expo Router: stacks, tabs, modals, protected screens and deep links
  • Data on a phone: reaching an API from a device, TanStack Query tuned for mobile, secure and local storage, keyboard-friendly forms and an offline-first log that syncs safely
  • Device features: permissions, the camera and photo library, location and maps, notifications, haptics, sharing and files
  • Animation and gestures with Reanimated 4 and Gesture Handler, and motion that respects reduced-motion settings
  • Accessibility for VoiceOver and TalkBack, testing with Jest and React Native Testing Library, performance and debugging
  • Shipping: app config and environments, development builds, EAS Build and Update, crash reporting and the app stores, with the real costs

Who This Course Is For

  • You have finished React + TypeScript: Build a Modern Web App, or you already work with React 19, TypeScript and the libraries it teaches
  • Web developers who want to build for phones without learning Swift and Kotlin first
  • Anyone with an app idea that needs the camera, location or notifications, or that has to work at the beach with one bar of signal

✅ What you need before you start

React and TypeScript, as taught in React + TypeScript: Build a Modern Web App: components and hooks, typed props, TanStack Query, Zustand, React Hook Form with Zod, and a test runner. This course does not reteach them; it shows what changes on a phone. You also need a computer (Windows, macOS or Linux) and, ideally, an iPhone or Android phone. No phone? The Android emulator and the web preview cover almost every lesson.

💡 Same project, second app

In the React + TypeScript course you built Shoreline Crew HQ, the organizers' web app. Here you build the volunteers' phone app for the same group, against the same shoreline-api and with the same TypeScript types. You will see exactly which parts of a web app's code carry over to mobile and which have to be rewritten, which is the question every team asks when it adds a phone app.

🌊 What You'll Build

Shoreline Crew is a (fictional) volunteer group that cleans up six beaches on its stretch of coast. Its volunteers need an app in their pocket. You build it, one lesson at a time:

  • Cleanups: upcoming cleanups in a fast scrolling list, a screen for each with the meeting point and a map, and sign-up and cancel in one tap
  • Your crew profile: sign in, see your sign-ups, stay signed in securely between launches
  • On the beach: check in with the day's code and your location, log what you collect even with no signal, and sync it when you are back online without creating duplicates
  • Photos: take or pick a photo of the haul and upload it
  • Reminders and polish: a local reminder before a cleanup, haptics, sharing a cleanup with a friend, animated tallies and swipe gestures
  • Quality and shipping: screen-reader support, tests, a development build, over-the-air updates and a release checklist for both stores
  • Your own app (Module 10): plan, build and ship an app from a client brief

🧭 What Runs Where

A phone app runs on a phone, but you write it on a computer. Here is where each part happens, honestly, including what costs money:

WhereWhat it is forWhat you need
Expo Go on your phoneThe quickest way to see your app on a real device: scan a QR code and it loads (Lesson 1.2 onward)A free app from the App Store or Google Play, and your phone and computer on the same Wi-Fi network
Android emulatorA virtual Android phone on your computer: great when you have no Android phone or no shared Wi-FiAndroid Studio (free) on Windows, macOS or Linux, and a computer with virtualization turned on
iOS SimulatorA virtual iPhoneA Mac with Xcode (free); there is no iOS simulator for Windows or Linux
Web previewThe same app in your browser (Expo's web support): handy for layout and quick checks, but not a phone (no camera, notifications or native look)Nothing extra
shoreline-api on your computerThe app's data: the same mock API as the HQ course, started with one command and reachable from your phone over Wi-FiNode.js 24 or newer
EAS in the cloudDevelopment builds, store builds and over-the-air updates (Module 9)A free Expo account; the free plan has a monthly build allowance
The app storesPublishing (Lesson 9.4, optional)Google Play: a one-time developer fee. App Store: a yearly Apple Developer Program fee. The lesson shows the current costs and what you can do without paying

⚠️ No Mac, no iPhone?

You can still take the whole course. Expo Go runs on any recent Android or iPhone, the Android emulator runs on Windows, macOS and Linux, and EAS builds iOS apps in the cloud without a Mac. Steps that need an iPhone or a Mac are marked, with what you would see.
