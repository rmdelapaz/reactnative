📱 Instructor-Led Course Syllabus · React Native & Expo

React Native & Expo: Build and Ship a Mobile App

An instructor-led course in 26 three-hour sessions, in three parts that can each run on their own. Take the React and TypeScript you know to iPhone and Android with Expo: native components and layout, fast lists, navigation, real data that survives a dropped connection, the camera, location and notifications, animation, accessibility, tests and a store-ready build.

Course site: rays-reactnative.netlify.app

26 sessions × 3 h78 class hours37 lessons2–3 h homework per sessionEach part runs aloneExpo SDK 58 · React Native 0.88 · TypeScript 6

📚 Course Description

React Native turns React components into the phone's own native views, and Expo is the framework around it: the CLI, the SDK of native modules, Expo Router, Expo Go and cloud builds. A React developer who knows TypeScript can ship a real iPhone and Android app from one codebase, without Swift, Kotlin or a Mac.

Every command and every listing in the course was run on Node.js 24 LTS with Expo SDK 58 (React Native 0.88, React 19.3, Expo Router 58, TypeScript 6.0), TanStack Query 5, Zustand 5, React Hook Form with Zod 4, Reanimated 4, Jest 30 with React Native Testing Library 14 and MSW 3; every lesson's project code is type-checked, linted, bundled for web, Android and iOS and checked in the web preview (and, from Module 8 on, tested with Jest). Steps that only a real phone can show are written from the official documentation and say so. One project runs through every lesson: Shoreline Crew, the volunteers' phone app of a fictional beach-cleanup group, built against the same small typed mock API as the prerequisite course's web app.

🎯 By the end you will be able to

  • Explain how React Native renders native views, what Expo adds, and how the development loop reaches a phone
  • Build screens from the core components with StyleSheet, flexbox, images, icons, fonts, safe areas, touch and input
  • Make the UI responsive, platform-aware, themed and accessible, and render long lists fast
  • Navigate with Expo Router: file-based routes, tabs, modals, sign-in flows, protected routes and deep links
  • Reach the API from a phone with TanStack Query, store data on the device, build mobile forms and work offline
  • Use device features with permissions done right: camera and photos, location and maps, notifications, haptics, sharing and files
  • Animate with Reanimated and gestures, test logic and screens with Jest, RNTL and MSW, and prepare development builds, updates and store releases with EAS

Each part runs on its own: Part 1 (Sessions 1 to 9, 27 class hours, 10 lessons) takes you from React on the web to a styled, interactive phone app with fast lists; Part 2 (Sessions 10 to 17, 24 hours, 14 lessons) adds navigation, real data, offline storage and the phone's features; Part 3 (Sessions 18 to 26, 27 hours, 13 lessons) adds motion, accessibility, tests, performance and a store-ready build. Parts 2 and 3 open with a refresher and the catch-up code.

✅ Prerequisites

  • React and TypeScript, the way React + TypeScript: Build a Modern Web App teaches them (or equivalent): React 19 components, props, state and hooks, typed data, TanStack Query, Zustand, React Hook Form with Zod and a test runner. No mobile experience, Swift, Kotlin or Mac needed.
  • A Windows 10/11, macOS or Linux laptop on which you may install software (Node.js, VS Code and Git), with several gigabytes of free disk space. An iPhone or Android phone with the free Expo Go app is recommended; the web preview (or an optional emulator) works without one.
  • The workspace is set up at home before Session 1, following Lesson 1.2: Node.js LTS, VS Code with Expo Tools, the course's mock API (shoreline-api, no installation), an Expo SDK 58 project, Expo Go on your phone if you have one, and the kit's labs installed once. Session 1 has an environment check and an install clinic.
  • Starting with Part 2 or Part 3 only: the earlier parts or equivalent experience (Part 2: core components, layout, input and lists in an Expo app; Part 3: an Expo Router app with data, storage and device features). Each part opens with a refresher and the catch-up code.

💡 Format

26 sessions × 3 hours = 78 class hours, one or two lessons per session (Sessions 9, 17, 26 teach no new lesson: project check-ins, assessments and the showcase; Sessions 2, 3, 4, 5, 6, 7, 20, 21, 23 teach one lesson each and give the rest of the time to a checkpoint or project work), in three parts: Part 1, Foundations and Lists (Sessions 1 to 9), Part 2, Navigation, Data and Devices (Sessions 10 to 17) and Part 3, Motion, Quality and Shipping (Sessions 18 to 26). Every lesson on the course site is written for a solo learner and takes about 125 to 160 minutes, so two lessons do not fit whole in one room session. The room protects what is hardest alone: the mental model, a live demo you type along with, a guided lab with help on hand, and starting each lesson project. At home you finish the projects and do each lesson's exercises, quiz and journal entry on the free course site: about two to three hours between sessions.

Each session runs 0:00 to 3:00: a warm-up on last session, the first lesson, a 10-minute break, the second lesson (or the rest of a one-lesson session), and a wrap-up with an exit ticket and the next bring list. One-lesson sessions add a checkpoint or project time; Sessions 9, 17 and 26 are project check-ins, assessments and the showcase.

Each part runs on its own: Part 1 (Sessions 1 to 9, 27 class hours, 10 lessons) takes you from React on the web to a styled, interactive phone app with fast lists; Part 2 (Sessions 10 to 17, 24 hours, 14 lessons) adds navigation, real data, offline storage and the phone's features; Part 3 (Sessions 18 to 26, 27 hours, 13 lessons) adds motion, accessibility, tests, performance and a store-ready build. 🏁 Checkpoints, Assessment and Project

  • Self-checks and exit tickets in every session are practice, not grades: they tell you and your instructor what to revisit.
  • Checkpoint 1 (Session 4), Checkpoint 2 (Session 13) and Checkpoint 3 (Session 21), 30 minutes each: short individual tasks on the modules just finished, scored with a short rubric.
  • Part 1 project and assessment (Sessions 8 and 9): a small phone app for a fictional client (typed screens and components, layout, touch and input and a themed list, from local typed data), scored with a six-row rubric, plus an individual assessment on Modules 1 to 3 (a written part and a practical, 20 points). Part 1 is met when the project has no rubric row at 0 and the assessment scores 14 or more (70 %).
  • Part 2 project and assessment (Sessions 16 and 17): a small app for another client with routes and tabs, a simple sign-in, data from its own small mock API, an offline-safe queue and one device feature, plus a written assessment on Modules 4 to 6 (20 points). Part 2 is met on the same rule: no rubric row at 0 and 14 or more (70 %).
  • Final project (Sessions 25 and 26). From a brief, you plan, build, test and prepare your own app for release, present it and review a classmate's. A well-reasoned modest project scores as well as an elaborate one. Nothing in the rubric needs money: a free launch route (a preview build, a recording on a phone, or the web preview for an app without device features) is enough. The course is complete when the final project is complete under Lesson 10.1's rubric (no row at "not yet") and the written final assessment is passed: 19 of 27 points (70 %).

🧰 Required Software and Data

  • Node.js: the current LTS release, 24 or newer, with npm
  • A code editor: VS Code (free) with the Expo Tools extension; the ESLint extension is recommended
  • A way to run the app: Expo Go (free) on your own iPhone or Android phone on the same Wi-Fi as your computer, or the web preview in your browser; the Android emulator and the iOS Simulator (Mac only) are optional
  • The course API: shoreline-api, a free download that runs with one command (no install, no account)
  • Accounts (Part 3 only): a free GitHub account for Session 24's CI workflow and the final project; a free Expo account is optional (cloud builds and updates in Sessions 23 and 24); no store account, no paid developer account, no store submission and no cloud build is required to pass

The workspace is set up once, at home, before Session 1, following Lesson 1.2 (Node.js LTS, VS Code with Expo Tools, the course API and an Expo SDK 58 project, opened in Expo Go or the web preview). Your instructor sends a setup guide and an environment check a week ahead; Session 1 has an install clinic for anything that went wrong. Learners starting with Part 2 or Part 3 get the catch-up code from the course downloads.
